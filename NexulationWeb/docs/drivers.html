Installing Drivers

How to install Drivers

About driver installer tools and Windows Update

A lot of users install their drivers incorrectly by using a driver installer tool or Windows Update. Do not use any of these methods. Driver installer software in the best case scenario will install a faulty or outdated driver. Worst case scenario, it might break your Windows install and/or cause a BSOD. Windows Update is just inherently bad when it comes to updating drivers. It struggles to properly identify hardware and often installs older driver.

What drivers do you need?

In the installation tutorial, we mentioned that the absolute bare minimum of drivers is the network drivers. After installing Windows, you most likely only need drivers for whatever hardware is not working on your PC.

I.e. If Wi-Fi is working, but not your Bluetooth and Audio devices properly, you only need to download your Bluetooth and Audio drivers; there is (mostly) no point in downloading the Wi-Fi driver.

Warning
  • Make sure to install Intel Dynamic Tuning and CPPC drivers if supported to avoid general performance issues.
  • Laptops with a dedicated NVIDIA or AMD graphics card, make sure to also install your integrated graphics drivers; To install it, look up your CPU model and add integrated graphics drivers at the end on your favorite search engine, otherwise adjusting brightness or screen refresh rate won't work.

Locating your drivers

The best way to find the driver of non-functional hardware is to simple Google it. The general idea is that you should only download drivers from the official website of the hardware manufacturer.

PC (Motherboard)

Search for your exact motherboard model (e.g., ASUS ROG Strix B650-E, MSI MAG Z790 Tomahawk) on the manufacturer's support portal to grab Chipset, LAN, and Audio drivers.

Laptop

Use your laptop's serial number or exact product line (Lenovo Legion, ASUS TUF, Acer Nitro) on the official support site to get power management and touchpad drivers.

Other hardware

For dedicated sound cards, capture cards, or high-speed USB Wi-Fi dongles, acquire drivers directly from the component vendor.

GPU drivers

Always download GPU drivers directly from NVIDIA, AMD, or Intel. Strip background telemetry using NVCleanstall for NVIDIA cards.

Installing the driver

Extract the installer archive if zipped, right-click `setup.exe` or `install.bat`, and select Run as Administrator. Reboot your system after major driver updates.

Troubleshooting

If Device Manager displays an unknown device with a yellow exclamation mark, right-click the device > Properties > Details > Hardware Ids to identify the vendor and device ID (VEN_xxxx&DEV_xxxx).

A last resort

If an obscure device refuses to install, temporarily enable Windows Update in NexulationTool to fetch the WHQL driver, then pause updates once verified.
