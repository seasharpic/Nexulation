Post-Install Guide

The Nexulation playbook is carefully configured and tweaked to achieve stability while still maintaining excellent performance and compatibility. Having said that, there's only so much that we can do on our end.

Certain components are specific to each PC, like drivers, BIOS, hardware etc. We simply cannot pre-tweak these kinds of components, as it is impossible to do while still retaining our focus on high compatibility with most systems.

However, this does NOT mean that we cannot help you tweak those things yourself. Any Nexulation install is very capable out of the box, but if you want the absolute optimal experience, we recommend that you follow and apply the Post-Install guide.

Activating Windows

Nexulation may activate itself automatically upon installation, using the OEM key connected to your BIOS, just like any other Windows version would do.

Nexulation does not provide any means of illegitimate Windows activation. Any attempt to activate Windows in an illegitimate way is strictly against our policy and is not supported or endorsed by Nexulation!

If your Nexulation installation isn't automatically activated, follow one of the methods listed down below.

Method 1 - Windows Settings

1. Open Settings (Win + I) and navigate to System > Activation.

2. Click Change product key and enter your official Windows 10/11 digital license key.

3. Select Activate to complete online digital entitlement.

Method 2 - Control Panel

1. Open Control Panel and select System and Security > System.

2. Scroll down to Windows Activation and click Change product key.

Method 3 - Command Prompt

Run Command Prompt as Administrator:

slmgr.vbs /ipk YOUR-PRODUCT-KEY-HERE
slmgr.vbs /ato

Recommended first steps

Follow these essential configuration steps to achieve maximum stability and latency reduction on your new installation.

Set time and language

Configure your local keyboard layout, language packs, and regional time zones in Settings > Time & Language.

GPU drivers

Download clean graphics drivers from NVIDIA, AMD, or Intel. For NVIDIA cards, we recommend using NVCleanstall to remove background telemetry services.

Other Device drivers

Refer to the dedicated Installing Drivers Guide for motherboard chipset, network, and audio driver setup procedures.

DirectX Runtime

Legacy DirectX 9/11 titles require the DirectX End-User Runtimes Web Installer to prevent missing DLL errors (`d3dx9_43.dll`, etc.).

NVIDIA Control Panel Tweaks

Open NVIDIA Control Panel

Right-click your desktop and select NVIDIA Control Panel.

Adjust Image Settings with Preview

Select Use the advanced 3D image settings.

Manage 3D Settings

  • Low Latency Mode: On or Ultra
  • Power Management Mode: Prefer Maximum Performance
  • Texture filtering - Quality: High Performance

Configure Surround PhysX

Set PhysX processor explicitly to your discrete NVIDIA GPU.

Change resolution

Ensure maximum refresh rate (e.g. 144Hz, 240Hz, 360Hz) is selected under PC resolutions.

Adjust desktop color settings

Optionally adjust Digital Vibrance to 55%-65% for improved visibility in games.

Adjust desktop size and position

Set scaling mode to No scaling or Display scaling to minimize input lag.

Setup G-SYNC

Enable G-SYNC for Fullscreen mode if using a compatible variable refresh rate monitor.

Adjust video color settings

Select With the NVIDIA settings > Advanced > Dynamic Range: Full (0-255).

Adjust video image settings

Disable edge enhancement and noise reduction to reduce GPU processing overhead.
