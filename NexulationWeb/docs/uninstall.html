Uninstall

The uninstallation process only works for Nexulation 2.0 and later versions.

To uninstall Nexulation completely without losing files and apps, you need to follow these steps:

1. Open Nexulation Tool → Windows Updates
  • Disable Pause Windows Updates and Hide the Windows Updates page
2. Open Terminal as administrator and run the following commands:
& "${env:ProgramFiles}\Nexulation Tool\nexulationtool.exe" winpackage --uninstall system-components-removal
& "${env:ProgramFiles}\Nexulation Tool\nexulationtool.exe" winpackage --uninstall defender-removal
& "${env:ProgramFiles}\Nexulation Tool\nexulationtool.exe" winpackage --uninstall ai-removal
& "${env:ProgramFiles}\Nexulation Tool\nexulationtool.exe" winpackage --uninstall onedrive-removal
Errors may occur during the uninstallation of some packages. This is normal and can be ignored.

Make sure to restart your computer after running the commands.

3. Open the Recovery page in Settings
4. Click on the Reinstall now button in the Fix problems using Windows Update
5. Follow the on-screen instructions to reset your system
