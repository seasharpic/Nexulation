Hardware & BIOS

Hardware & BIOS Configuration

Enabling XMP / EXPO

RAM default speeds run at standard JEDEC frequencies (2133MHz / 4800MHz). Enable XMP (Intel), DOCP (ASUS AMD), or EXPO (AMD DDR5) in BIOS to run your memory at rated speeds and tight sub-timings.

Resizable BAR (ReBAR)

Resizable BAR enables the CPU to negotiate full access to GPU VRAM framebuffers in a single request, eliminating PCIe transfer bottlenecks in DirectX 12 and Vulkan games.

In BIOS: Enable Above 4G Decoding and set Re-Size BAR Support to Auto or Enabled.

Updating BIOS/UEFI

Keep your motherboard BIOS updated to receive AGESA microcode updates (AMD) or Microcode 0x12B fixes (Intel 13th/14th Gen stability).
